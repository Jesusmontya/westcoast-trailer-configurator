Aprendizajes técnicos de esta sesión (para no repetir):

Cuidado al correr comandos de creación de carpetas — deben correrse desde la raíz correcta del repo para evitar anidamiento duplicado
npm create vite@latest . falla si la carpeta no está vacía — usar carpeta temporal (temp-vite) y copiar con cp -r temp-vite/. . en vez de mv
El GITHUB_TOKEN automático de Codespaces NO tiene permiso para crear repos vía gh repo create — hay que crear el repo desde la web de GitHub primero
Vercel necesita que el "Root Directory" apunte a la subcarpeta correcta (website) cuando el proyecto Next.js no vive en la raíz del repo
